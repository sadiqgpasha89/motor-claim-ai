11 Bounded Specialised Agents

Implemented in agents/specialists.py inheriting from BoundedAgent. Calling any tool outside allowed_tools raises ToolPermissionError.

Agent Allowed Tools Hard Safety & Governance Boundary
fnol_conciergecreate_intimation, policy_lookup, faq_retrieval, request_uploadNever blocks registration for missing docs; cannot decide coverage
document_intelligenceevidence_read, ocr_extract, schema_validate, duplicate_checkQuarantines prompt injection; marks OCR unverified until human review
coverage_intelligencepolicy_read, policy_rag, deterministic_coverage_rulesProduces clause-cited factsheet; never repudiates autonomously
claim_triageclaim_facts_read, triage_rules_read, queue_recommendRoutes EV, TP injury, and ≥ ₹50k losses using operational signals only
damage_assessmentvision_model, image_quality_check, vehicle_taxonomySeparates visible_observed vs inferred_possible
estimate_validationparts_catalogue, rate_card_read, estimate_parser, duplicate_line_rulesFlags duplicate lines & >12% variance without silently altering quotes
fraud_intelligencefraud_feature_service, fraud_rules, entity_graph_queryAlert-only with benign explanations; never rejects or holds payout alone
provider_coordinationverified_roster_read, provider_scorecard, schedule_notifyBlocks unlicensed surveyors; respects customer garage selection
settlement_recommendationdeterministic_calculator, policy_facts_read, survey_report_readAlways returns needs_human for Maker-Checker DoA sign-off

Quick Start & Seeded Edge Cases

.venv/bin/uvicorn apps.api.main:app --reload --port 8000
cd apps/web && npm install && npm run dev
